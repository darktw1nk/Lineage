# Pass 19 — adversarial hunt against pass 18 (`9614fa8`)

Four parallel hunters, every finding proven with a runnable harness; one hunter
dedicated to the previous pass's own diff, per the standing method. The method
held again: **five of the nineteen findings were regressions pass 18 itself
introduced.** Suite before: 131 files / 1226 tests. After the fixes: 133 files /
1249 tests, green, type-check clean.

## Fixed in this pass

**Pass-18 regressions (hunter A):**
1. The echo check's `startsWith` arm was unconditional, so a FAITHFUL
   application of a full-rewrite edit — byte-equal to the edit text — was
   rejected as an echo, observed live: 3/3 deterministic retries, a legitimate
   rewrite discarded, 4 calls billed. Fix: an echo is only evidence when the
   instruction is EDIT-language (`isEditLanguage`: an imperative about the
   prompt), not replacement text.
2. The edit-list-shape rejection ran before the JSON-parent exemption, making
   labeled-taxonomy JSON prompts (`[{"label":"positive"},…]`) permanently
   un-operable — crossover threw on every child of every generation. Fix:
   parent-genre exemptions computed first; the ACTUAL edits payload echoed
   back is still rejected for every genre.
3. Pass 18 doubled the worst-case operator calls (apply retries too) but the
   liveness budget stayed at 6×callTimeoutMs — a live operator at retries > 2
   was declared hung and its billed spend dropped. Fix: the budget scales with
   `2×retries + 2`.
4. Prose-preamble evasion: `"Here is the new prompt:\n[{…}]"` — the exact
   open-bugs #2 artifact — passed the whole-text JSON parse. Fix: an
   edit-shaped array constituting ≥60% of the reply is rejected.
5. Whitespace-reflow no-ops passed both gates (exact trim equality) and
   re-bought the paid-no-op outcome. Fix: collapsed comparison everywhere,
   carrying the parent's raw prompt so the cache serves it.

Also from hunter A: line-shaped scaffolding detection (a bash herestring's
mid-line `<<<` is not a fence; the template's `Original: <<<` line still is);
zero-width characters stripped before echo comparison; a CARRY-labeled no-op
no longer keeps operator-effectiveness credit.

**Budget integrity (hunter B).** Correction first: `reserveCall` is a
settled-spend check wearing reservation comments — there is no live hold. On
top of that, pass 18's retry loops multiplied the unchecked billing window:
one gate, then up to 2×retries billed calls (measured 160× a tight cap at
default retries), and a generation transition froze the gate for the whole
child batch because operator spend accrued in one lump afterwards (measured
4.6×). Fixes: operators receive `shouldAbort(spentSoFarUSD)` and check it
between their own calls (budget-abort carries the parent honestly);
`createNextGeneration` settles each child through `budget.accrueChild` the
moment it completes; the estimator's retry factor now covers the real
per-operator ceilings and its warning names the `2×retries` bound; the lying
reservation comments now say what the code does. docs/cli.md updated to match.

**Desktop wiring (hunter C).** `holdoutSkippedReason` was persisted but never
crossed IPC — the pass-18 "share rounded to zero" tile could only appear after
an app restart. It now rides the terminal `cost_breakdown` event and the store
consumes it (replay-fidelity covers both live paths). And a Stop between the
two holdout halves no longer `return`s past the tail emission: the champion
half's spend is reported as `skipped: manual` in the same session it happened.

**Report honesty (hunter D).** A champion that IS the seed no longer prints a
fabricated "[MUTATION] Seed prompt (baseline)" entry (the honest branch was
unreachable); a non-string judge `justification` no longer crashes the report
after the run was paid; "neither side could not be graded" reads as English
now; test NAMES are escaped in the Analysis buckets; one-sided tests are
disclosed as "not comparable" instead of vanishing; bare URLs can no longer
autolink out of the artifact (scheme broken with a ZWSP, built from
`String.fromCharCode` — never a literal invisible in source); `traceLineage`
is cycle-guarded; the default report path no longer nests
`testoutputs/testoutputs/`; doubled sentence-final periods trimmed. Plus the
all-carry disclosure: a run where ≥half the children carried unchanged now
says so loudly in the report (hunter A's "clean-looking dead run").

## Known-remaining (documented, not fixed)

- A hung operator's detached spend still never reaches cost tracking — the
  cost isn't knowable at timeout; the scaled liveness budget makes the false
  positive rare rather than impossible.
- The dead reservation state fields (`reservedUSD`, `callCeilingUSD`,
  `maxObservedCallUSD`, `observedCompletion`) are still initialized and
  written but never read — cleanup candidate, no runtime effect.
- `isEditLanguage` is a heuristic: an edit that is BOTH edit-language and its
  own replacement text ("Add a rule: never translate") still favors rejection
  when echoed verbatim at the head of a reply.
- The desktop Footer surfaces no carry-share warning (the report does).
