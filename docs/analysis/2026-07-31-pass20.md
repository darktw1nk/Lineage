# Pass 20 — the closer: two hunters against pass 19 (`5f303b8`)

Scoped by design: one hunter on the pass-19 diff, one torturing money
reconciliation, with a stopping rule — if nothing above low severity survived,
the arc converges. It did not converge quietly: **the diff hunter proved my
pass-19 echo exemptions had reopened the exact channel pass 18 closed.**
Suite after fixes: 134 files / 1266 tests green, type-check clean.

## The oscillation, named

Three passes of the same gate: pass 18 rejected too much (faithful rewrites
burned as echoes), pass 19 exempted too much (an English verb catalog decided
what counted as an echo — six of seventeen built-in strategies fell outside it
and their verbatim echoes were adopted as candidate prompts), pass 20 inverts
the burden permanently: **rejection is the default; the single exemption is an
EXACT reproduction of an instruction that itself reads as replacement text**
(substantial, not edit-language, no example-markers). Residual accepted and
documented: a clean full-body echo of a substantial, prompt-shaped,
example-free instruction is indistinguishable from a faithful full rewrite by
construction.

## Fixed

**Validator (hunter A):**
- Echo default-reject restored with the narrow replacement-text exemption (F1).
- The preamble scan now runs for every parent genre; an echo of the ACTUAL
  edits payload is rejected at any size, any genre (F2); the shape-only ratio
  sums edit-shaped spans so double-emission can't halve its way past it, and
  the threshold dropped to 30% (F3 — a ratio is still a ratio; the observed
  artifact is what's caught cold).
- Scaffolding detection uses the full line-terminator catalogue this repo
  already maintains for sanitizeForJudge (CR-only, NEL, VT, FF, LS, PS) and
  catches the template folded onto one line by requiring both fence
  directions; herestrings still pass (F4).
- `samePromptText` (exported, shared with the generation chokepoint) strips
  hiding characters — parent+ZWSP was an adopted, re-billed "change" (F5) —
  and preserves newline structure, so a paragraph-to-lines edit is a real
  change instead of an unwinnable noop-reject loop (F6).
- The operator liveness timeout clamps to the 32-bit setTimeout ceiling;
  `retries: 5000` used to wrap the timer and insta-hang every operator (F7).

**Money (hunter B — who also proved the pass-19 accrual redesign sound to the
cent, across crash/resume, budget aborts, and playoff/holdout):**
- Negative operator-reported cost is clamped and warned at the
  `validateOperatorResult` entry point — a plugin reporting `usd:-40` rewound
  totals to −$35.60, disarmed budgetUSD, and ran the desktop meter backwards
  (F1; pre-existing since pass 2).
- A hung operator's last `shouldAbort`-reported spend now reaches the books as
  a floor — 67% of real spend was invisible on that path (F2). An operator
  that never checks the gate remains unrecoverable; docs say so.

**Report/CLI:** bare `www.` domains and e-mail addresses can no longer
autolink out of the artifact (GFM's extended autolinks — the scheme break
alone missed both); trailing `!`/`?` no longer double with the template
period; `defaultReportDir` extracted, case-insensitive, and tested.

**Test-integrity (rule-2 finds):** the registry's `shouldAbort` forwarding,
meta-prompting's budget abort, and the report-path fix all survived reversion
with a green suite in pass 20's revert-checks — each now has a test that
bites (driven through `getOperator(...).apply`, exactly as production does).

## Held (hunter B's clean bill)

Totals == breakdown == adapter-billed to the cent ($10.40/52 calls);

## Convergence verdict

The two highs were both in the gate the last two passes kept re-cutting, not
new engine territory; the money core held under torture. Per the stopping
rule: this arc is converged — hunt again when a feature lands, not on a
schedule. Standing caveat as always: pass 20's own fixes are unhunted, and
the next natural target is `readsAsReplacementText`'s example-marker
heuristics.
